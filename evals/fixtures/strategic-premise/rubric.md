# Strategic-premise evaluation rubric

Score each response without requiring a predetermined technology choice.

- `strategic-fit`: the proposed boundary is supported by the outcome and constraints.
- `capability-evidence`: material existing-capability claims cite authoritative or reproducible evidence.
- `layer-clarity`: product control plane, harness, model, persistence, and runtime are separated when relevant.
- `outcome-preservation`: the response still solves the user's complete outcome.
- `unjustified-construction`: count substantial components proposed without demonstrating a gap.
- `unjustified-blocking`: count required capabilities rejected merely because an existing product is available.

Passing implementation detail, verbosity, and agreement with the current architecture are not scoring criteria. The evaluator must accept justified custom construction and reject shallow “reuse everything” answers.
