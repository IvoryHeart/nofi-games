# Claude Code entry point

`AGENTS.md` is the canonical repository instruction file. Read it and its mandatory documents before acting.

Codex is the primary coding harness. Claude Code remains a supported adoption path and does not need an active role in ordinary Codex work.

When deliberately assigned work, use Claude Code's native threads, subagents, tools, permissions, context management, authentication, and model execution. Do not construct a provider runtime or second harness. Consume the same OpenSpec agreements, Git state, and deterministic checks without depending on Codex conversation state.

For concurrent writable work, follow [the native harness runbook](docs/runbooks/native-harness-workflow.md).
